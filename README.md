# BUTD-EDA

This repository contains the two codebases used for the shared-module experiments:

- `BUTD/`: BUTD implementation, experiment scripts, tests, and reproducibility documents.
- `EDA/`: EDA implementation, experiment scripts, tests, and reproducibility documents.

The paper-facing shared module boundary is kept consistent across both codebases: SACR + RAPF + QAHNL.

## Repository scope

Datasets, checkpoints, training logs, TensorBoard/W&B outputs, caches, compiled extensions, and other generated artifacts are intentionally excluded. Follow the README and environment configuration inside each subdirectory to prepare dependencies and data locally.
